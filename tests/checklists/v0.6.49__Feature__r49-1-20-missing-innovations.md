# Human Test Checklist: R49, the innovations a fresh 1.20 game lists

**Target version:** 0.6.49
**Ships with commit:** `b721321` v0.6.49: R49 gives 1.20 cultures the innovations a fresh game lists
**Companion automated tests:** `tests/test_innovations.py` (5: the shared core's evidence and keep-what-is-there rules, G1, R47 on the founding campaign, R49's core on a 1.20 re-save), plus the rule-list pins in `tests/test_rules.py`, `tests/test_patches_pack.py`, `tests/test_update.py`, `tests/test_core_without_dazzlecmd_lib.py` and the CLI output golden. Suite at release: 1739 passed, 13 skipped.

## What this is

A culture in Crusader Kings III can research only the innovations it lists, and a new 1.20 game lists all 108 on every culture. A 1.8 save lists only 1.8's innovations, and the game's first 1.20 load never adds Pole Vault or Legacy of Persia's fritware and mural sextant. R49 adds every missing innovation when a save is updated for 1.20. It adds only an innovation the reference save gives every culture, and it leaves alone any entry a culture already has. This checklist is for a person with the game and a 1.8 save, to see the result where the game shows it.

## Prerequisites

1. The tool installed (`pip install -e .` from the repo, or `pip install ck3-save-updater==0.6.49`).
2. A 1.8 save (`old.ck3` below) and a 1.20 reference save (`ref.ck3`: a new 1.20 game, saved on day one).
3. A 1.20 game install, for the steps that load the result. The checks before that need only Python.
4. **Isolation:** write every output to a scratch folder, never over your save. The tool never writes in place. Name any save you load in the game `MIGRATE_TEST__...`, so you can tell it apart from your own.

## High-Value Verification (~5 minutes)

### HV.1: the rule is listed and runs by default

- [ ] **Steps** (same in every shell): `ck3update rules`
- [ ] **Expected:** a line `R49 missing-innovations` between R32 and R7, with the description "give every culture the innovations a fresh 1.20 game lists on every culture ...".
- [ ] **Why this matters:** a rule missing from the list is a rule nobody runs.

### HV.2: an updated save lists every innovation on every culture

- [ ] **Steps:** `ck3update migrate old.ck3 --reference ref.ck3 --report r.json -o <scratch>/out.ck3`
- [ ] **Expected:** the run's summary has an `R49 missing-innovations` line with `matched` above 0. In `r.json`, R49's `extra` lists "innovations added", including `innovation_pole_vault`, `fp3_innovation_fritware` and `fp3_innovation_mural_sextant`.
- [ ] **Why this matters:** these three are what the game itself never adds.

### HV.3: without a reference, R49 is skipped and says why

- [ ] **Steps:** the same migrate, without `--reference`.
- [ ] **Expected:** R49 is not run (it needs a reference, like the religion and new-map rules), and the rest of the update completes.
- [ ] **Why this matters:** a missing reference must never fail the whole update.

### HV.4: in the game, a carried culture can research Pole Vault

- [ ] **Steps:** copy `out.ck3` into your save games folder as `MIGRATE_TEST__r49.ck3`; load it in 1.20; open your culture's innovations.
- [ ] **Expected:** Pole Vault is listed, undiscovered unless your culture's era and template say otherwise. If your DLC has them, fritware and the mural sextant are listed too.
- [ ] **Why this matters:** this is the player's view of the fix; the save checks above only predict it.

### HV.5: a second run changes nothing

- [ ] **Steps:** run migrate again on `out.ck3` (same reference) to `<scratch>/out2.ck3`.
- [ ] **Expected:** R49 reports `matched 0`. No culture gains a second entry.
- [ ] **Why this matters:** an update run twice must not double-write.

## Section 1: what R49 leaves alone

### 1.1 An entry a culture already has keeps its progress

- [ ] **Steps:** pick a culture in `old.ck3` with an innovation in progress (the save shows `progress=` under it). Run migrate.
- [ ] **Expected:** that innovation's progress is unchanged in `out.ck3`, and it appears once.

### 1.2 Only innovations the reference gives every culture

- [ ] **Steps:** read R49's `extra` in `r.json`.
- [ ] **Expected:** no key "left alone (the reference lists them on some cultures only)" with a real reference (none is expected from a new 1.20 game). If you use a modded reference that restricts an innovation to some cultures, that innovation must appear there and must not be added.

## Section 2: the 1.21 path is unchanged

### 2.1 R47 still adds only 1.21's own innovations

- [ ] **Steps:** load `out.ck3` in 1.21 and save it; run the 1.21 repair with a 1.21 reference.
- [ ] **Expected:** R47's "innovations added" are 1.21's new innovations only. Pole Vault and the two Persia innovations are not among them, since R49 already added them.

## What the automated tests DON'T cover

- The game's own view: whether the added innovations show and can be researched (HV.4).
- DLC differences: a game without Legacy of Persia, and what it does with the two fp3 innovations (a fresh game without the DLC still lists them? not measured).
